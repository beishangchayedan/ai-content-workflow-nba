# 体育运动员能力面板 · NBA 专项资料

**[进入篮球与足球统一作品集](https://beishangchayedan.github.io/ai-content-workflow/)**

作品展示、历史问题与解决方法统一在一个站点维护。本仓库保留 NBA 专项证据、制作模板和旧版合成实验；原网址自动跳转到统一作品集。

项目负责人定义内容需求、制定评分与视觉标准、审核争议项和验收结果；AI 协助检索、结构化资料、编写工具及执行检查。这里展示内容运营与 AI 协作能力，不把 AI 生成代码等同于负责人独立编程能力。

## 篮球专项范围

截至 **2026-09-16**，正式 NBA 项目为 **13 个主题、229 个阶段节点、687 张 3840×2160 PNG**。11 个主题使用可编辑审查入口，2 个历史主题仅有只读入口。数量是文件交付规模，不代表独立球员数、视频数、流量或收入。

当前数量与 PNG 头部尺寸已核验。保存、刷新恢复和故障回滚的证据仅覆盖各报告注明的历史测试范围，未在本轮对全部 13 个主题重做功能测试。公开证据是去隐私的第一方摘要，并非第三方认证。

篮球与足球共用身份核验、评分与视觉分离、人工修订保护、授权检查、交付验收和工作区清理方法；**各自评分公式、维度及历史版本分别保留**。

## 旧版实验与复验

`lab.html` 使用虚构人物、合成数据、原创几何图形和系统字体。16 项均值仅用于实验，**不是 NBA 或足球正式评分公式**。浏览器存储不等于生产项目的正式写盘、修订与回滚。

实验支持编辑、重新复核、授权缺失阻断、PNG/JSON 导出、JSON 导入和刷新恢复。`index.html` 只负责跳转；[浏览器验收记录](evidence/demo-verification.json) 分别绑定入口和实验源码哈希，不作为统一总站的功能验收。

```sh
python -m http.server 8000 --bind 127.0.0.1
# 访问 http://127.0.0.1:8000/lab.html
```

可选浏览器测试需要 Node.js 20+：

```sh
npm install
npx playwright install chromium
npm test
```

测试使用独立临时浏览器；`CHROME_PATH` 可指定已有 Chrome，`ARTIFACT_DIR` 指定测试输出位置。不要在正式生产项目或个人资料目录运行测试。入口跳转目标通过拦截请求验证，线上总站另行验收。
